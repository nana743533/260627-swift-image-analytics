# 260627-swift-image-analytics

Swift を使用した画像解析プロジェクト。

Swiftの勉強をしたい。モバイルが不慣れ。ハッカソン中にXcodeでビルドするだけでもすごく時間がかかったので、基本的な知識をつけて、素早くアプリを作れるようにするためのキャッチアップ。
